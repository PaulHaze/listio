Listio is intended to be a personal tool for me to be able to grab public facing movie and tv show lists from Simkl, Trakt, MDBlists and IMDB's own lists, combine them, have them de-dupe and then have me be able to go through and remove any titles in there I dont want, and then publish that final list in a way that can be added to a collection within Nuvio. 

Workflow:
- Web GUI has a box where I can paste the list URL
- Fetches the list of shows/movies in the background
- I can press a small + button to get another URL box to add another list
- This can continue until I have added all the various lists
- A button says 'Review List' which takes me a to a large grid of the movies in the list, with an artwork thumbnail cover, next to that will be the title and then a short description. There will be a check box and a trashcan icon by each movie. If I click the trashcan the movie/show is removed. If I want to remove multiple then I can use the check box and then remove all selected with a button at the bottom of the screen.
- The only functionality of this web app is to combine movie lists and have the ability to remove items from the list. We do not need to be able to search for movies or add individual ones. 
- However we DO need to be able load up the manifest.JSON and edit further (add another list, or remove existing titles in the list) and then be able to re-save that and have the collection in Nuvio use the most recent version of the manifest. 

This is just for me for now, but I would like to make the functionality of this public potentially.
